# Employee Payroll Management System

A Employee Payroll Management System developed using Core Java and Object-Oriented Programming concepts. The project manages full-time and part-time employees, performs salary calculations, and demonstrates real-world payroll processing functionality.

---

## Features

- Add employees to payroll system
- Remove employees using Employee ID
- Display employee details
- Salary calculation for different employee types
- Supports:
  - Full-Time Employees
  - Part-Time Employees

---

## Technologies Used

- Core Java
- IntelliJ IDEA
- Collections Framework
- OOP Concepts

---

## OOP Concepts Used

- Inheritance
- Polymorphism
- Encapsulation
